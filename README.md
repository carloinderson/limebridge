# Limebridge Financial & Advisory Services — website

Statische, tweetalige (NL/EN) corporate website van Limebridge Financial and Advisory Services N.V.

- `index.html` — pagina-opbouw (HTML)
- `css/style.css` — vormgeving (CSS)
- `js/main.js` — interactie: fotowissel, taalkeuze, diensten, formulier (JavaScript)
- `img/` — logo's en foto's

Hosting: Render (static site), publish directory `.`, geen build command.
